# 4.04a Tipar las interfaces de proveedores

**Objetivo:** TTL, usage, esfuerzo y deltas tienen contratos compartidos comprobados por mypy.

**Lee:** `cachetap/providers/base.py`, `anthropic.py`, `openai.py`, `__init__.py` completos; `cachetap/record.py`; `tests/test_dependencies.py`; `pyproject.toml`; `contratos.md` (Tipos).

**Puedes tocar:** `cachetap/providers/base.py`, `cachetap/providers/anthropic.py`, `cachetap/providers/openai.py`, `cachetap/providers/__init__.py`, `tests/test_dependencies.py`, `pyproject.toml`.

## Pasos

1. Anota todas las funciones de los cuatro módulos, incluidos generadores: owns→bool, version→tuple[int,int] o None, cache_ttl→record.CacheTTL, normalize→record.Usage o None, effort→str o None, deltas→tuple[list[str],str o None], written_ttl→int o None.
2. Entrada JSON usa record.JsonObject/JsonValue y usage events usa list[record.UsageEvent]. Usa narrowing local para estructuras externas; conserva los filtros de valores inválidos introducidos en 2.02.
3. Define TypedDict locales `TTLHelpRow` y `MinimumHelpRow` donde se construyen las tablas, con campos actuales obligatorios y la misma forma estructural entre proveedores. El despacho define el contrato `Reference` con esas listas y reviewed. No introduzcas un protocolo de proveedor ni clases para los módulos del registro PROVIDERS.
4. Añade record a dependencias permitidas de despacho/Anthropic/OpenAI. base solo utiliza str y tuples y conserva su dependencia vacía. Amplía mypy.files a los cuatro módulos.
5. Conserva orden de PROVIDERS, TTL, mínimos y datos de ayuda. No silencies errores con Any o ignores globales.
