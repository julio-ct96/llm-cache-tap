3. Cubre estos resultados observados; no fijes como correcto el recuento de caracteres de `input` ni los errores de inputs mal formados.

| Caso actual | Entrada | Resultado observado que se fija |
| --- | --- | --- |
| POST reconocido | Un mensaje `hola`, modelo Claude | ID 1, `pending`, `tap_id=1`, cuerpo 1 retenido |

| Límite FIFO | MAX=2, IDs 1,2,3 | IDs y cuerpos 2,3 |
| Escapado | Texto con `&`, `<`, `>`, comillas dobles | Entidades HTML correspondientes |
| Estado UI inicial | Nueva importación | Maps vacíos, selección null, TTL 300 |
