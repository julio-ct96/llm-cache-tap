# 2.06 Acotar respuestas y capturas simultáneas

**Objetivo:** los buffers del inspector tienen límites explícitos sin modificar el tráfico.

**Lee:** `tap.py` (`responseheaders`, `response`, `error`, `done`); `cachetap/store.py`; `cachetap/response_body.py`; `cachetap/verdict.py`; `tests/replay/flows.py`; `tests/test_flows.py`; `contratos.md` (Límites y Diagnósticos).

**Puedes tocar:** `cachetap/config.py`, `cachetap/store.py`, `cachetap/record.py`, `tap.py`, `tests/replay/adapter.py`, `tests/test_flows.py`, `tests/test_store.py`.

## Pasos

1. Añade MAX_RESPONSE_BYTES y MAX_ACTIVE_CAPTURES. Añade `ACTIVE_CAPTURES` como set de IDs en store y funciones `begin_capture(id)`/`end_capture(id)`, llamadas bajo LOCK. El reset de tests lo vacía.
2. Al llegar headers reserva slot; si no existe slot, captura marcada active_captures y sin chunks. El stream siempre devuelve el mismo objeto bytes recibido.
3. Cuenta bytes antes de guardar cada chunk. Al superar el máximo, vacía chunks, marca response_size y libera slot. Los demás chunks pasan sin retención. Conserva los tiempos ya medidos.
4. En response libera slot en finally y limpia chunks/metadata de captura, incluso si el registro se expulsó. Si limitada, no parses el buffer ni llames a judge: aplica los campos y nota del contrato; publica y persiste como cualquier respuesta completada.
5. En error libera slot y chunks; en done vacía reservas tras parar el dashboard. La expulsión de un registro no libera por sí sola un buffer aún en uso: se libera al terminar/error/límite.

| Caso nuevo | Resultado |
| --- | --- |
| Buffer exactamente al límite / un byte más | Inspección normal / captura limitada sin buffer |
| Límite pequeño con UTF-8 multibyte | Cuenta bytes, no caracteres |
| 16 slots ocupados y otra respuesta | Sin reserva ni buffer; N/A al finalizar |
| Fin/error de un slot y nueva respuesta | Slot reutilizable |
| Registro expulsado antes del fin | Reserva liberada igualmente |
| Usage válido antes de exceder el límite | No se emite HIT/PARTIAL de captura incompleta |
