# 2.03 Quitar filesystem de los imports

**Objetivo:** importar configuración no crea directorios y el log inicializa únicamente su destino al escribir.

**Lee:** `cachetap/config.py`; `cachetap/store.py` (`append_log`); `tests/test_config.py`; `tests/test_store.py`; `tests/replay/adapter.py` (`reset`).

**Puedes tocar:** `cachetap/config.py`, `cachetap/store.py`, `tests/test_config.py`, `tests/test_store.py`.

## Pasos

1. Elimina `DATA.mkdir` del cuerpo de `config.py`.
2. En `append_log`, crea `config.LOG.parent` con parents/exist_ok justo antes de abrir; usa `encoding='utf-8'` explícito.
3. Prueba la ausencia de mkdir durante `importlib.reload(config)` mediante mock de `Path.mkdir`. Restaura configuración al terminar. Prueba escritura a un destino temporal anidado inexistente; no uses DATA real.

| Caso | Resultado: contrato nuevo |
| --- | --- |
| Import/reload config | Cero llamadas a mkdir |
| Log temporal con padre inexistente | Se crea el padre y una línea JSON UTF-8 con `ñ` |
| Padre ya existente | Append conserva líneas anteriores |

## Verificación

- `venv/bin/python -m unittest tests.test_config tests.test_store -q`: `OK`.
- TESTS: `OK`; golden idéntico.
