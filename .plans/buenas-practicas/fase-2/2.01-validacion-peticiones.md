# 2.01 Validar peticiones en la entrada

**Objetivo:** las formas de JSON no inspeccionables dejan pasar la llamada sin romper el hook.

**Lee:** `tap.py` (`request`); `cachetap/segments.py` completo; `cachetap/providers/anthropic.py` (`cache_controls`, `effort`); `cachetap/providers/openai.py` (`cache_ttl`, `effort`); `tests/test_flows.py`; `contratos.md` (Diagnósticos y Casos).

**Puedes tocar:** `cachetap/request_body.py` (nuevo), `tests/test_request_body.py` (nuevo), `tap.py`, `tests/test_flows.py`, `tests/test_dependencies.py`.

## Pasos

1. Crea `request_body.parse(text)`: devuelve un objeto inspeccionable o lanza `ValueError` con razón fija. JSON sintácticamente roto conserva el comportamiento existente: devuelve `{}`. Captura `json.JSONDecodeError` y `RecursionError` del decoder; para este último rechaza la inspección.
2. Valida antes de calcular segmentos: raíz dict; `model` ausente/null/string; `tools` ausente/null/list de objetos; `messages` ausente/null/list; `input` ausente/null/string/list; effort en `output_config`, `reasoning`, `reasoning_effort` ausente/null/string. No rechaces elementos escalares de `input` o `messages`: el replay contiene `42`.
3. Recorre el JSON con pila explícita para verificar una profundidad máxima nueva de 100 contenedores y que cada `cache_control.ttl` sea ausente/null/string; así no llegan objetos no hashables a `TTL_NAMES.get` ni recursión excesiva a segmentación. No modifiques el cuerpo transmitido ni elimines campos desconocidos.
4. En `request`, captura solo `ValueError` de ese helper, emite warning sin cuerpo y retorna. Añade `request_body.py: set()` a dependencias.
5. Calcula `n_msgs` con la misma selección actual `messages or input or []`, pero cuenta una cadena no vacía como un mensaje.

| Caso | Resultado: contrato nuevo salvo JSON roto |
| --- | --- |
| Raíz `[]`, null, número o string JSON | Sin registro ni `tap_id`; warning fijo |
| `tools=7`, `messages=7`, `input={}` | Sin registro; llamada intacta |
| TTL dict o effort list | Sin registro; no TypeError posterior |
| `input='hola'` | `n_msgs=1`; segmento `msg0:text` |
| `input=['texto',42]` | Dos mensajes, compatible con replay |
| Profundidad 100 / 101 | Admitida / rechazada; ningún stack overflow |
| JSON roto existente | Registro igual al actual |
