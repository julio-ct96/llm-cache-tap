# 2.02 Tolerar eventos de respuesta mal formados

**Objetivo:** los eventos no utilizables se ignoran sin perder los eventos válidos posteriores.

**Lee:** `cachetap/response_body.py` completo; `cachetap/providers/__init__.py` (`deltas`, `normalize`); `cachetap/providers/openai.py` (`deltas`, `normalize`); `cachetap/providers/anthropic.py` (`deltas`, `normalize`); sus tests y `contratos.md` (Casos).

**Puedes tocar:** `cachetap/response_body.py`, `cachetap/providers/__init__.py`, `cachetap/providers/openai.py`, `cachetap/providers/anthropic.py`, `tests/test_response_body.py`, `tests/test_providers.py`, `tests/test_providers_openai.py`, `tests/test_providers_anthropic.py`.

## Pasos

1. Captura `json.JSONDecodeError`/`RecursionError` al leer eventos, y llama a `providers.deltas` solo con objetos dict.
2. En OpenAI acepta `choices` solo si es list y cada choice/delta solo si es dict; `finish_reason`/stop reason y textos solo si son strings. Aplica también el filtro string al stop reason de Anthropic.
3. En `normalize`, descarta eventos cuyo usage no sea dict. Para los campos de tokens utilizados, admite enteros no negativos y excluye bool; ignora valores inválidos al fusionar. Normaliza los details solo si son dict, sus contadores con la misma regla. Limita read al total en OpenAI para no producir uncached negativo. Mantén todos los resultados válidos actuales.

| Caso | Resultado |
| --- | --- |
| SSE válido de Anthropic | Existente: `('Hola mundo','end_turn')` |
| SSE válido Responses / Chat | Existente: `('Hola mundo',None)` / `('Hola mundo','stop')` |
| `data: []`, null, 42 y luego delta válido | Contrato nuevo: solo el texto válido |
| `choices` escalar, choice null, delta list | Contrato nuevo: ignorados; no excepción |
| Tokens string/bool/negativos; details list | Contrato nuevo: ignorados, sin aritmética inválida |
| cached_tokens mayor que input total | Contrato nuevo: read=total y uncached=0 |
