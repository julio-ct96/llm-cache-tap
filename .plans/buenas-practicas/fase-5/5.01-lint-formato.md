# 5.01 Ruff y formato consistente

**Objetivo:** todo el Python de producción tiene un estilo automatizado y una comprobación reproducible.

**Lee:** `requirements-dev.txt`, `pyproject.toml`, `.gitignore`, todos los módulos Python de producción; excepciones de imports en tap.py.

**Puedes tocar:** `requirements-dev.txt`, `pyproject.toml`, `.gitignore`, `tap.py`, `cachetap/config.py`, `cachetap/record.py`, `cachetap/request_body.py`, `cachetap/segments.py`, `cachetap/linking.py`, `cachetap/verdict.py`, `cachetap/response_body.py`, `cachetap/store.py`, `cachetap/dashboard.py`, `cachetap/providers/__init__.py`, `cachetap/providers/base.py`, `cachetap/providers/anthropic.py`, `cachetap/providers/openai.py`.

## Pasos

1. Añade `ruff==0.14.0` a requirements-dev e instala mediante pip con TLS verificado. Es una baseline publicada, no una promesa de usar la última versión. Si falla la instalación, marca bloqueada.
2. Configura Ruff target-version py312, line-length 100, reglas E4/E7/E9/F/I, formato comillas dobles. Añade `.ruff_cache/` a gitignore. No actives reglas de complejidad arbitrarias ni límites de líneas de funciones.
3. tap.py necesita la recarga de módulos antes de importar cachetap: aplica solo un noqa E402 a ese import con comentario de causa. No ignore E402 para todo el repositorio. No cambies el orden semántico del bootstrap.
4. Ejecuta `venv/bin/python -m ruff check --fix tap.py cachetap` y `venv/bin/python -m ruff format tap.py cachetap`. Revisa cada arreglo; solo estilo/imports no utilizados, sin cambios de lógica. No formatees los tests ni el golden en esta tarea.

## Verificación

- LINT: `All checks passed!`.
- FORMAT: código 0 sin ficheros pendientes de formato.
- TYPES y TESTS pasan; golden idéntico.
