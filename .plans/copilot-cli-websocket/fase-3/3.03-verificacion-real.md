# 3.03 Comprobar una llamada real económica

**Objetivo:** Validar con la instalación del usuario que una inferencia real aparece en el inspector.

**Lee:** `scripts/check_copilot.py`: CLI, restricciones y limpieza; `protocolo.md`: evidencia, alcance y coste; `verificacion-real.md` del plan.

**Puedes tocar:** `.plans/copilot-cli-websocket/verificacion-real.md`.

## Pasos

1. Esta tarea es optativa y puede consumir cuota. La autorización del usuario en la conversación fue para llamadas triviales, con modelos baratos y poco contenido; no la extiendas a campañas, prompts largos ni modelos premium. Si no dispones de esa autorización al retomar, pide confirmación y no la ejecutes.
2. Comprueba que las tareas técnicas de las dependencias están terminadas. No instales ni autentiques Copilot. Si falta acceso, marca esta tarea bloqueada sin bloquear la entrega offline.
3. Ejecuta una única vez `"$RAÍZ/venv/bin/python" "$RAÍZ/scripts/check_copilot.py" --run-real`. Si copilot no está en PATH y no se localiza automáticamente, usa --copilot con la ruta absoluta que el usuario haya facilitado; no gastes una llamada para resolver una ruta.
4. Acepta cualquier veredicto de caché que provenga de usage válido, incluido COLD o PARTIAL. No hagas otra llamada solo para provocar un HIT.
5. Si el runner falla, anota el motivo y para: no hagas una segunda ejecución ni cambies de modelo por iniciativa propia. El diagnóstico se hará con tests sintéticos o con una revisión del plan.
6. En el fichero autorizado registra fecha, versión del CLI, modelo seleccionado, número de peticiones, créditos reportados si están disponibles, igualdad de contadores, registro capturado y resultado de limpieza. No guardes cuerpos, IDs reales de sesión, rutas personales ni tokens.
7. Si la prueba usa otro protocolo, marca bloqueada. No anuncies compatibilidad general con Gemini, Anthropic, otros hosts o multiplexación: no están cubiertos por este plan.

## Verificación

- El comando anterior termina en 0 y resume una captura WebSocket con uso coincidente y una sola petición del modelo, o se registra honestamente el bloqueo sin reintentar.
- PLAN-CHECK pasa.
- `git status --short` no muestra nuevos datos, certificados ni cambios de código atribuibles a esta tarea.
