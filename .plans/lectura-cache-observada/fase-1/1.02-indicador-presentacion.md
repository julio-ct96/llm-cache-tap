# 1.02 Crear el indicador común de lectura observada

**Objetivo:** disponer de un fragmento de interfaz puro, todavía sin montar, que no dependa de cliente, modelo, transporte ni veredicto.

**Lee:** `ui/parts.js` (`badge`, `shareBar`); `ui/format.js` (`pct`); `ui/css/parts.css` (`.badge`, `.v-hit`, `.bar`); `ui/css/tokens.css`; `tests/ui/unit/baseline.test.mjs` (patrón de test).

**Puedes tocar:** `ui/parts.js`, `ui/css/parts.css`, `tests/ui/unit/cache-read.test.mjs` (nuevo).

## Pasos

1. Exporta `cacheReadIndicator(r)` desde `ui/parts.js`. Procesa únicamente registros `state === 'done'`; en otros estados devuelve HTML vacío, no `0 %` y no «sin datos».
2. En `done`, lee `usage.read` e `usage.input_total`. El par es válido solo si ambos son enteros seguros de JS, `input_total > 0` y `0 <= read <= input_total`. No conviertas strings, no apliques defaults ni recortes valores inválidos. Con par inválido o ausente presenta el texto visible **`Lectura de caché: sin datos`**; no muestres un porcentaje ni uses el estilo verde. Este indicador no intenta corregir la normalización de proveedores.
3. Con par válido el texto visible es **`Leído de caché: {porcentaje}`**. Reutiliza el `pct` del proyecto con un decimal. Resuelve solo la ambigüedad del umbral: cuando `read / input_total < 0.9` y `pct` redondee a `90,0 %`, muestra **`Leído de caché: <90 %`** (escapa el signo `<` en el HTML). El verde depende de la fracción sin redondear, no del texto. No reutilices `badge(r)` ni `.v-hit` para el indicador.
4. Devuelve un único `span` con clase base `.cache-read`; añade `.cache-read-high` solo para el tramo verde. Para el par no disponible, mantiene únicamente la clase base. En `parts.css`, `.cache-read` reutiliza `.badge` mediante un selector compartido, manteniendo las reglas existentes de `.badge` y añadiendo al nuevo indicador solo `white-space: nowrap` y el texto neutro `--dim`. `.cache-read-high` comparte el relleno `--kiwi` con `.v-hit` y usa `--on-accent` para el texto. No añadas efectos, valores de color, radios, fuentes o tamaños nuevos. Conserva `badge` y `shareBar` tal como están.
5. Testea la clase base, el modificador, el texto visible/escapado y la ausencia de `.v-hit`. Usa solo `node:test` y `node:assert/strict`. No crees una API nueva para exponer el cálculo.
