# 1.05 Elección de tarifa y referencia de precios

**Objetivo:** `cachetap/prices/__init__.py` decide qué tarifa paga una petición y entrega las tablas de precios para la ayuda.

**Lee:** `TARIFF` y `PRICES` de los tres ficheros de `cachetap/prices/`; `PROVIDERS` y `owns` en `cachetap/providers/`; la tabla `ALLOWED` de `tests/test_dependencies.py`; `files` de mypy en `pyproject.toml`.

**Puedes tocar:** `cachetap/prices/__init__.py` (nuevo), `tests/test_prices.py` (nuevo), `tests/test_dependencies.py`, `pyproject.toml`.

## Pasos

1. Crea el fichero con estas constantes:

   | Constante | Valor |
   | --- | --- |
   | `REVIEWED` | `octubre de 2026` |
   | `TARIFFS` | las tablas en el orden de la ayuda: `copilot`, `anthropic`, `openai` |
   | `LIST` | pares de proveedor y tabla de lista: `providers.anthropic` con `anthropic`, `providers.openai` con `openai` |

2. Añade `lookup(host, model)`, que devuelve el nombre de la tarifa y la fila del modelo:

   | Caso | Tarifa | Fila |
   | --- | --- | --- |
   | `copilot.serves(host)` | `Copilot` | la de `copilot.PRICES` para el nombre canónico, o nulo; **sin** recurrir a un precio de lista |
   | otro host y un proveedor de `LIST` es dueño del modelo | el `TARIFF` de su tabla | la de su `PRICES`, o nulo |
   | ningún proveedor es dueño | nulo | nulo |

   El host se compara en minúsculas; host y modelo pueden ser nulos.

3. Añade `reference()`, que devuelve `prices` (una fila por modelo de cada tabla de `TARIFFS`, con `tariff`, `model` y `price`) y `prices_reviewed`.

4. Añade a `ALLOWED` la fila `prices/__init__.py` con `providers`, `prices.anthropic`, `prices.base`, `prices.copilot` y `prices.openai`, y el fichero a `files` de mypy.

5. Crea `tests/test_prices.py` con las clases `LookupTest` y `ReferenceTest`:

   | Test | Entrada | Resultado esperado |
   | --- | --- | --- |
   | host de Copilot | `api.githubcopilot.com`, `claude-opus-5.5` | `Copilot`; entrada 4; sin `write_1h` |
   | host en mayúsculas | `API.GitHubCopilot.com`, `gpt-6-luna` | tarifa `Copilot` |
   | llamada directa | `api.anthropic.com`, `claude-haiku-4-5-20251001`; `api.openai.com`, `gpt-6-luna` | `Anthropic` con `write_1h` = 2; tarifa `OpenAI` |
   | Copilot no recurre a la lista | `api.githubcopilot.com`, `gpt-5.2` | `Copilot` y nulo |
   | modelo sin precio | `api.openai.com`, `gpt-5.2` | `OpenAI` y nulo |
   | proveedor desconocido | `api.mistral.ai`, `mistral-large`; nulo, nulo | nulo y nulo |
   | forma de la referencia | `reference()` | claves `prices` y `prices_reviewed`; fecha `octubre de 2026` |
   | filas | `reference()["prices"]` | 60 filas; tarifas `Copilot`, `Anthropic` y `OpenAI`; cada fila con `tariff`, `model`, `price`; leído ≤ entrada |
   | nombres canónicos | cada `model` de `prices` | `base.canonical` lo deja igual |
