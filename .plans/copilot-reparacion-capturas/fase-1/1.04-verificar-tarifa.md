# 1.04 Verificar la tarifa Copilot ausente

**Objetivo:** Obtener una fila oficial completa para Gemini 4 Argon o dejar su coste explícitamente desconocido.

**Lee:** `evidencia.md`, sección Precios; `cachetap/prices/copilot.py::PRICES`, `cachetap/prices/__init__.py::lookup`, `reference`, `REVIEWED`; `cachetap/prices/base.py::Price`, `canonical`, `long_context`.

**Puedes tocar:** `contratos/precios.json`, `contratos/precios.md` (nuevo). Además, solo tu fila del índice.

## Pasos

1. Confirma la ausencia actual con BASELINE. Solo busca `gemini-4-argon`; no conviertas la tarea en actualizar todo el catálogo.
2. Consulta documentación pública oficial de GitHub Copilot sobre modelos y precios. Registra URL, fecha de consulta, vigencia, nombre exacto y sección de la fila. Si hay remisión explícita a otro tarifario oficial, cita también esa remisión. No uses el catálogo OpenCode ni una tarifa de Google sin prueba de que Copilot la aplica.
3. Crea `contratos/precios.md` con secciones `Fuentes`, `Fila y unidades`, `Caché y contexto`, `Vigencia`, `Decisión`. Completa la tabla siguiente solo con datos acreditados:

   | Campo | Comprobación exigida |
   | --- | --- |
   | Modelo y canal | gemini-4-argon servido por Copilot |
   | input/read/output | USD por millón de tokens, sin confundir créditos ni multiplicadores |
   | Escritura de caché | Si se factura aparte y cuál es su tarifa; no inventar cero |
   | Contexto largo | Si existe umbral, alcance a toda la petición y tarifas de cada parte |
   | Vigencia/promoción | Fechas y condición aplicable a la captura histórica frente a peticiones nuevas |

4. Actualiza el JSON con `sources`, `decision` y `unknowns`, manteniendo `approved=false`. Usa `status=verificado` solo si se puede codificar una fila sin supuestos. En caso contrario, `status=insuficiente` y decisión de conservar `cost_missing`.
5. No escribas tarifas, no recalcules capturas antiguas, no cambies REVIEWED y no añadas un proveedor directo de Google. El orquestador debe convertir la evidencia aprobada en la tabla de valores exactos de 2.03.

## Verificación

- CHECK y PLAN-CHECK pasan; `git diff --check` no muestra nada.
- BASELINE sigue pasando: la consulta de Argon continúa devolviendo tarifa Copilot con precio desconocido.
- GATE precios sigue en `BLOCKED`, código 1, hasta auditoría. Ningún código ni test de precios del usuario cambió.
