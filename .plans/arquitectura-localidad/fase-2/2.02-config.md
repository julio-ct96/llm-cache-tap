# 2.02 `config.py`

**Objetivo:** sacar de `tap.py` las rutas, los puertos y los límites.

**Lee:** `tap.py`, el bloque de constantes (desde `HERE = ...` hasta `STATE = ...`) y `tests/replay/adapter.py`.

**Puedes tocar:** `cachetap/config.py` (nuevo), `tap.py`, `tests/replay/adapter.py`, `tests/test_config.py` (nuevo).

## Pasos

1. Crea `cachetap/config.py` con un docstring de una línea y estas constantes, movidas desde `tap.py`:

   | En `tap.py` | En `config.py` | Cambio |
   | --- | --- | --- |
   | `HERE` | `ROOT` | ahora es la carpeta **padre** de `cachetap/` (dos niveles por encima del fichero) |
   | `DATA` | `DATA` | `ROOT / "data"` |
   | `DATA.mkdir(exist_ok=True)` | igual | se mueve tal cual |
   | `LOG` | `LOG` | sin cambio |
   | `UI` | `UI` | `ROOT / "ui"` |
   | `UI_PORT` | `UI_PORT` | sin cambio |
   | `TTL_FORCED` y su comentario | `TTL_FORCED` | sin cambio |
   | `TTL_S` | `TTL_S` | sin cambio |
   | `MAX` | `MAX` | sin cambio |

   Se quedan en `tap.py`: `MIME`, `TTL_NAMES`, `LLM_PATHS`, `FIRST_TOKEN`, `STATIC_SEG`, `SAFE_HEADER`, `UNSAFE_HEADER`, `HEAVY`, `LOCK`, `RECORDS`, `BODIES`, `CLIENTS`, `STATE`.

2. En `tap.py`, después del bloque de recarga, añade `from cachetap import config`.
3. En `tap.py` sustituye cada uso por su versión con prefijo:

   | Nombre | Dónde se usa |
   | --- | --- |
   | `LOG` → `config.LOG` | `response` |
   | `UI` → `config.UI` | `Handler._static` (2 veces) |
   | `UI_PORT` → `config.UI_PORT` | `load` (2 veces) |
   | `TTL_FORCED` → `config.TTL_FORCED` | `cache_ttl` (2 veces), `response` (1 vez) |
   | `TTL_S` → `config.TTL_S` | `cache_ttl` (1 vez), `judge` (1 vez), `Handler._events` (1 vez) |
   | `MAX` → `config.MAX` | `request` |

4. En `tap.py` quita los imports que ya no se usan: `os` y `Path`.
5. En `tests/replay/adapter.py`: importa `from cachetap import config`; `reset` asigna `config.LOG` en lugar de `tap.LOG`; `set_max` lee y asigna `config.MAX` en lugar de `tap.MAX`.
6. Crea `tests/test_config.py` con estos tests:
   - `config.ROOT` es la carpeta que contiene `tap.py` (existe el fichero `config.ROOT / "tap.py"`).
   - `config.UI` es `config.ROOT / "ui"` y `config.DATA` es `config.ROOT / "data"`.
   - `config.MAX` es 300.
   - `config.TTL_S` es igual a `config.TTL_FORCED or 300`.

   Este test no compara `config.LOG`, porque otros tests lo sustituyen.

## Verificación

- El tamaño de `RAÍZ/data/requests.jsonl` no cambia por ejecutar los tests.
- PROXY según `reglas.md`.
