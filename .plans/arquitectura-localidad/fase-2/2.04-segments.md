# 2.04 `segments.py`

**Objetivo:** mover a un módulo puro el troceado de la petición, las huellas y el diff.

**Lee:** `tap.py`: de la sección `# ---------- request analysis ----------` las funciones `_strip`, `_dump`, `_hash`, `_preview`, `_seg`, `seg_objs`, `segments`, `first_diff`; y las funciones `request` y `link_to_previous`.

**Puedes tocar:** `cachetap/segments.py` (nuevo), `tap.py`, `tests/test_segments.py` (nuevo).

## Pasos

1. Crea `cachetap/segments.py` con un docstring de una línea e importa solo `hashlib`, `json` y `re`. Mueve estas funciones desde `tap.py`, con estos nombres:

   | En `tap.py` | En `segments.py` |
   | --- | --- |
   | `_strip` | `strip` |
   | `_dump` | `dump` |
   | `_hash` | `digest` |
   | `_preview` | `preview` |
   | `_seg` | `seg` |
   | `seg_objs` | `seg_objs` |
   | `segments` | `segments` |
   | `first_diff` | `first_diff` |

   Dentro del módulo, actualiza las llamadas internas a los nombres nuevos (incluidas las llamadas recursivas).

2. **Único cambio de lógica**, en `first_diff`. Hoy recibe `(prev_id, name, req)` y lee el cuerpo anterior del global `BODIES`.
   Pasa a recibir `(prev_body, name, req)`, donde `prev_body` es el texto del cuerpo de la petición anterior o `None`:
   - Si `prev_body` es `None`, devuelve `None`.
   - Donde hacía `json.loads(BODIES[prev_id])`, hace `json.loads(prev_body)`.
   - El resto no cambia: sigue devolviendo `None` ante `KeyError` o `ValueError`.

3. En `tap.py`: añade `segments` al import de `cachetap` y elimina las ocho funciones. Sustituye sus usos:

   | Dónde | Antes | Después |
   | --- | --- | --- |
   | `request`, clave `_params` | `_dump(...)` | `segments.dump(...)` |
   | `request`, clave `segs` | `segments(req)` | `segments.segments(req)` |
   | `link_to_previous`, última línea | `first_diff(best["id"], diverge, req)` | `segments.first_diff(BODIES.get(best["id"]), diverge, req)` |

4. En `tap.py` quita el import `hashlib`, que ya no se usa.

5. Crea `tests/test_segments.py`:

   | Test | Comprobación |
   | --- | --- |
   | strip | `strip({"a": [{"cache_control": 1, "b": 2}], "cache_control": 3})` es `{"a": [{"b": 2}]}` |

   | digest | tiene 10 caracteres hexadecimales; `digest({"x": 1, "cache_control": {}})` es igual a `digest({"x": 1})`; `digest({"x": 1})` es distinto de `digest({"x": 2})` |
