# 2.05 `providers/base.py`

**Objetivo:** crear el paquete de proveedores con la utilidad que comparten: leer la versión de un nombre de modelo.

**Lee:** `tap.py`: la función `_version` y las funciones `cache_ttl` y `min_cacheable`, que la usan.

**Puedes tocar:** `cachetap/providers/__init__.py` (nuevo), `cachetap/providers/base.py` (nuevo), `tap.py`, `tests/test_providers_base.py` (nuevo).

## Pasos

1. Crea `cachetap/providers/__init__.py` con una sola línea: un docstring que diga `What each LLM provider does differently: cache lifetime, limits and wire format.`
2. Crea `cachetap/providers/base.py` con un docstring de una línea. Importa solo `re`. Mueve `_version` desde `tap.py` con el nombre `version`, sin más cambios.
3. En `tap.py`: después del import de `cachetap` añade `from cachetap.providers import base`; elimina `_version`; sustituye cada `_version(` por `base.version(` (1 vez en `cache_ttl`, 1 vez en `min_cacheable`).
4. Crea `tests/test_providers_base.py` con un test por fila:

   | `version(modelo, familia)` | Resultado |
   | --- | --- |
   | `("gpt-5.6-luna", "gpt")` | `(5, 6)` |
   | `("gpt-5-2025-08-07", "gpt")` | `(5, 0)` |
   | `("gpt-4o", "gpt")` | `(4, 0)` |
   | `("gpt-4.1", "gpt")` | `(4, 1)` |
   | `("claude-opus-4-7", "claude-opus")` | `(4, 7)` |
   | `("claude-opus-5-5", "claude-opus")` | `(5, 5)` |
   | `("mistral-large", "gpt")` | `None` |
   | `(None, "gpt")` | `None` |

## Verificación

- TESTS acaba en `OK`.
- `grep -n "_version" RAÍZ/tap.py` no muestra nada.
- PROXY según `reglas.md`.
