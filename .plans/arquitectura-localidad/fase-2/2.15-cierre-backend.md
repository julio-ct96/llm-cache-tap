# 2.15 Cierre del backend

**Objetivo:** dejar `tap.py` solo con los hooks y fijar con un test quién puede importar a quién.

**Lee:** `tap.py` entero y la primera línea de imports de cada fichero de `cachetap/`.

**Puedes tocar:** `tap.py`, `tests/test_dependencies.py` (nuevo).

## Pasos

1. Revisa `tap.py`. Debe contener **solo** esto, en este orden:
   - el docstring inicial, sin cambios;
   - imports de la librería estándar: `json`, `re`, `sys`, `time`. Quita cualquier otro que no se use;
   - el bloque de recarga de la tarea 2.01;
   - una línea `from cachetap import ...` con los módulos que se usan;
   - las constantes `LLM_PATHS`, `SAFE_HEADER`, `UNSAFE_HEADER`;
   - las funciones `_is_llm`, `request`, `responseheaders`, `response`, `error`, `load`, `done`.

   Si queda cualquier otra función, constante o import, no lo borres por tu cuenta: para y márcalo como `bloqueada`.

   Los comentarios de sección (`# ---------- nombre ----------`) que se hayan quedado sin código debajo sí se borran:
   son restos de las extracciones. Conserva solo `# ---------- mitmproxy hooks ----------`.

2. Crea `tests/test_dependencies.py`. Para cada fichero `.py` de `cachetap/` (incluidos los de `cachetap/providers/`), analiza su código con el módulo `ast`
   y reúne los módulos de `cachetap` que importa: `from cachetap import a, b` cuenta como `a` y `b`; `from cachetap.providers import x` cuenta como `providers.x`.
   Comprueba que cada fichero importa **como mucho** lo de su fila:

   | Fichero | Puede importar de `cachetap` |
   | --- | --- |
   | `config.py` | nada |
   | `record.py` | nada |
   | `segments.py` | nada |
   | `providers/base.py` | nada |
   | `providers/anthropic.py` | `providers.base` |
   | `providers/openai.py` | `providers.base` |
   | `providers/__init__.py` | `config`, `providers.anthropic`, `providers.openai` |
   | `response_body.py` | `providers` |
   | `linking.py` | `segments` |
   | `verdict.py` | `config`, `providers` |
   | `store.py` | `config`, `record` |
   | `dashboard.py` | `config`, `record`, `store` |

   Añade dos comprobaciones más: ningún fichero de `cachetap/` importa `tap`; y todo fichero `.py` de `cachetap/` (salvo `__init__.py` de la raíz del paquete) aparece en la tabla,
   para que un módulo nuevo obligue a decidir sus dependencias.
