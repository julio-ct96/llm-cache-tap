# 2.11 `linking.py`

**Objetivo:** mover a un módulo puro el emparejamiento de una petición con la anterior de su conversación.

**Lee:** `tap.py`: `STATIC_SEG`, `_common`, `link_to_previous` y `request`.

**Puedes tocar:** `cachetap/linking.py` (nuevo), `tap.py`, `tests/test_linking.py` (nuevo).

## Pasos

1. Crea `cachetap/linking.py` con un docstring de una línea. Imports: `re` y `from cachetap import segments`. Contenido:

   | Elemento | Definición |
   | --- | --- |
   | `STATIC_SEG` | movida desde `tap.py` |
   | `common(a, b)` | `_common` movida y renombrada |
   | `find_previous(rec, records)` | **primera mitad** de `link_to_previous`: desde `static = {...}` hasta el final del bucle `for prev in ...` que elige `best`. El bucle recorre el parámetro `records` en lugar de `RECORDS.values()`. Devuelve la pareja `(best, best_n)`. Se queda con el docstring de `link_to_previous` |
   | `link(rec, req, best, best_n, prev_body)` | **segunda mitad** de `link_to_previous`: desde `rec["conv"] = best["conv"]` hasta el final. Lleva un docstring de una línea: describe en `rec` qué cambió respecto a `best` |

   Dentro de `link` hay dos ajustes, porque las variables locales `static` y `msgs` ya no existen:
   - donde se usaba `static`, se usa `rec["_static"]`;
   - la última línea pasa a ser `rec["diff"] = segments.first_diff(prev_body, diverge, req)`.

   El bloque `if best is None:` **no** se mueve: se queda en `tap.py` (paso 2).

2. En `tap.py`: añade `linking` al import de `cachetap`; elimina `STATIC_SEG`, `_common` y `link_to_previous`.
   En `request`, la línea `link_to_previous(rec, req)` se sustituye por:
   - obtener `best` y `best_n` de `linking.find_previous(rec, RECORDS.values())`;
   - si `best` es `None`: las tres líneas del antiguo bloque `if best is None:` (asignar `rec["conv"]`, incrementar `STATE["next_conv"]`, asignar `rec["prev_id"] = None`), sin el `return`;
   - si no: `linking.link(rec, req, best, best_n, BODIES.get(best["id"]))`.

3. Crea `tests/test_linking.py`. Define una función auxiliar `make(req, **campos)` que devuelve un registro con
   `segs` = `segments.segments(req)`, `ts` = 0, `effort` = `None`, `model` = `"m"`, `_params` = `""`, más los `campos` recibidos.
   Una petición anterior se prepara con `make(...)`, dándole `id`, `conv`, `ts`, `ts_end` y `ttl_anchor`, y llamando a `find_previous(anterior, [])` para que tenga `_static` y `_msgs`.

   Peticiones de ejemplo: `P1` = `{"tools": [{"name": "t"}], "system": "s", "messages": [U1]}`;
   `P2` = igual con mensajes `[U1, A1, U2]`. `U1`, `A1`, `U2` son mensajes `{"role", "content"}` con textos distintos.

   | Test | Comprobación |
   | --- | --- |
   | common | `common([1, 2, 3], [1, 2, 4])` es 2; `common([], [1])` es 0 |
   | sin anteriores | `find_previous(make(P1), [])` es `(None, 0)`; el registro queda con `_static` de claves `tools` y `system`, y `_msgs` de longitud 1 |
   | otra conversación | con una anterior cuyo primer mensaje es distinto, devuelve `(None, 0)` |
   | empate | con dos anteriores hechas de `P1` (ids 1 y 2), `find_previous(make(P2), [a1, a2])` devuelve la de id 2 y `best_n` 1 |
   | prefijo intacto | anterior de `P1` (id 1, conv `c1`), actual de `P2`: tras `link`, `conv` es `c1`, `prev_id` es 1, `prefix_intact` es verdadero, `diverge_at` es `None`, no existe la clave `diff`, y los `same` de los segmentos son, en orden, verdadero, verdadero, verdadero, falso, falso |
   | system cambiado | actual = `P2` con `system` `"otro"`, `prev_body` = `json.dumps(P1)`: `prefix_intact` falso, `diverge_at` `system`, `diff["segment"]` `system` |
   | tools eliminado | actual = `P2` sin `tools`: `diverge_at` es `tools (eliminado)` y la clave `diff` existe con valor `None` |
   | edad desde el inicio | anterior con `ts` 100, `ts_end` 110, `ttl_anchor` `start`; actual con `ts` 160: `gap_s` 50.0 y `age_s` 60.0 |
   | edad desde el final | igual con `ttl_anchor` `end`: `age_s` 50.0 |
   | cambios | anterior con `effort` `None`, `model` `m`; actual con `effort` `high`, `model` `n`, `_params` `"x"`: `effort_changed`, `model_changed` y `params_changed` verdaderos; `prev_effort` `None`; `prev_model` `m` |
