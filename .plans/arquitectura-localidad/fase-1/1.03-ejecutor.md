# 1.03 Ejecutor del escenario

**Objetivo:** pasar una lista de pasos por los hooks con un reloj controlado y recoger todo lo que producen.

**Lee:** `tests/replay/flows.py`, `tests/replay/adapter.py`, `tests/replay/builders.py`.

**Puedes tocar (nuevos):** `tests/replay/scenario.py`, `tests/replay/steps_anthropic.py`, `tests/replay/steps_openai.py`,
`tests/replay/steps_misc.py`, `tests/test_scenario.py`, `tests/test_replay.py`.

## Pasos

1. Crea los tres ficheros `steps_*.py`. Cada uno contiene solo `STEPS = []`. Los rellenan otras tareas.

2. Crea `tests/replay/scenario.py`. No importa `tap`: usa solo `adapter`, `flows` y `builders`.

   **`BASE_TS = 1790000000.0`**

   **`Step`**: tupla con nombre o dataclass con estos campos, en este orden:

   | Campo | Significado |
   | --- | --- |
   | `key` | etiqueta del paso, por ejemplo `"A1"` |
   | `t` | segundos desde el inicio del escenario |
   | `host` | host de la petición |
   | `path` | ruta de la petición |
   | `body` | cuerpo: un diccionario (se serializa con `json.dumps(..., ensure_ascii=False)`) o un texto (se envía tal cual) |
   | `status` | código de estado de la respuesta |
   | `chunks` | lista de trozos de texto de la respuesta, o `None` para simular un error de red |
   | `expect` | veredicto esperado, o `None` si la petición debe ignorarse y no crear registro |
   | `method` | método HTTP; por defecto `"POST"` |

   **`all_steps()`**: devuelve `steps_anthropic.STEPS + steps_openai.STEPS + steps_misc.STEPS`.

   **`run(steps, base_ts=BASE_TS)`**. Hace, en orden:
   1. Guarda el valor actual de la variable de entorno `TZ`, la pone a `UTC` y llama a `time.tzset()`. Al salir (también si hay excepción) restaura `TZ` y vuelve a llamar a `time.tzset()`.
   2. Crea un directorio temporal con `tempfile.TemporaryDirectory()` que se borra al salir de `run`.
   3. Llama a `adapter.reset(<directorio>/requests.jsonl)` y a `adapter.subscribe()`.
   4. Sustituye `time.time` con `unittest.mock.patch("time.time", ...)` por una función que devuelve el valor de un reloj que controla `run`.
   5. Para cada paso, con `T = base_ts + step.t`:
      - Crea `FakeFlow(FakeRequest(step.method, step.host, step.path, <texto del cuerpo>, T))` y llama al hook `request`.
      - Si `step.chunks` es `None`: reloj = `T + 1.0`; `flow.error = "connection reset"`; llama al hook `error`. Fin del paso.
      - Si no: `flow.response = FakeResponse(step.status, builders.RESPONSE_HEADERS, T + 0.3)`; llama al hook `responseheaders`.
      - Si `flow.response.stream` no es `None`: para cada trozo, pon el reloj y llama a `flow.response.stream(<trozo en bytes UTF-8>)`.
        El reloj del primer trozo es `T + 0.5`, el del segundo `T + 0.8` y el del tercero y siguientes `T + 1.9`.
      - Reloj = `T + 2.0`; llama al hook `response`.
   6. Vacía la cola de la suscripción con `get_nowait()` hasta que lance `queue.Empty`.
   7. Lee las líneas del fichero jsonl temporal (si no existe, lista vacía) y convierte cada una con `json.loads`.
   8. Devuelve un diccionario con cuatro claves: `events` (los eventos de la cola, en orden), `records` (`adapter.records()`),
      `body_ids` (`adapter.body_ids()`) y `log_lines` (las líneas del paso 7).

3. Crea `tests/test_scenario.py` con un test que ejecuta `run` con un solo paso:
   `key="X1"`, `t=0`, host `api.anthropic.com`, ruta `/v1/messages?beta=true`, cuerpo `builders.claude_body("claude-opus-5-5", "X", 1)`,
   estado 200, trozos `builders.anthropic_sse(0, 3000, 20)`, `expect="COLD"`. Comprueba sobre el resultado:
   - `records` tiene 1 elemento, `body_ids` es `[1]`, `log_lines` tiene 1 elemento.
   - `events` tiene 3 elementos y los `rec.state` son, en orden, `pending`, `streaming`, `done`.
   - En el registro: `verdict` = `COLD`; `path` = `/v1/messages`; `time` = `14:13:20`; `hdr_s` = `0.25`; `ttft_s` = `0.75`; `total_s` = `1.95`;
     `output` = `Hola mundo`; `stop_reason` = `end_turn`;
     `usage` = `{"read": 0, "write": 3000, "uncached": 20, "input_total": 3020, "output": 50, "reasoning": None}`;
     las claves de `resp_headers` son exactamente `request-id`, `anthropic-ratelimit-requests-remaining` y `via`.

4. Crea `tests/test_replay.py` con un test `test_expected_verdicts`:
   - Ejecuta `run(all_steps())`.
   - `esperados` = lista de `step.expect` de los pasos cuyo `expect` no es `None`, en orden.
   - El número de registros debe ser `len(esperados)`.
   - El `verdict` del registro en la posición `i` debe ser `esperados[i]`. Si no coincide, el mensaje de fallo debe incluir la `key` del paso.

## Verificación

- TESTS con `-p 'test_scenario.py'` acaba en `OK`.
- TESTS completo acaba en `OK` (`test_replay` pasa con las listas vacías).
- El tamaño de `RAÍZ/data/requests.jsonl` no cambia por ejecutar los tests.
