# 1.07 Golden

**Objetivo:** guardar el resultado completo del escenario contra el `tap.py` actual y compararlo en cada ejecución.

**Lee:** `tests/replay/scenario.py`, `tests/test_replay.py`.

**Puedes tocar:** `tests/test_replay.py`, `tests/replay/golden.json` (nuevo).

## Pasos

1. En `tests/test_replay.py` añade el test `test_golden`:
   - `resultado` = `run(all_steps())` pasado por `json.loads(json.dumps(...))`, para que tenga los mismos tipos que un JSON leído de disco.
   - Si la variable de entorno `TAP_UPDATE_GOLDEN` vale `1`: escribe `resultado` en `tests/replay/golden.json` con
     `ensure_ascii=False`, `indent=1` y `sort_keys=True`, y termina el test.
   - Si no: lee `golden.json` y compáralo con `resultado`. Si difieren, el mensaje de fallo indica **solo la primera diferencia**:
     la sección (`events`, `records`, `body_ids` o `log_lines`), la posición en la lista, el `id` del registro, la clave, el valor esperado y el obtenido.
     No vuelques el JSON entero.

2. En el mismo fichero añade el test `test_known_values`, que ejecuta `run(all_steps())` y comprueba (los registros se buscan por su `id`):

   | Qué | Valor |
   | --- | --- |
   | número de `records` | 44 |
   | número de `events` | 131 |
   | número de `log_lines` | 43 |
   | `body_ids` | los enteros de 1 a 44 |
   | `notes` del registro 5 | `["pasaron 400 s desde el inicio de #4 (TTL 300 s, por defecto de Claude)"]` |
   | `diverge_at` del registro 6 | `system` |
   | `diff.segment` y `diff.offset` del registro 6 | `system` y `40` |
   | `diverge_at` del registro 7 | `tools (eliminado)` |
   | `notes` del registro 8 | `["cambió el modelo (claude-opus-5-5 → claude-sonnet-5-5)", "cambió el esfuerzo (high → low)", "cambiaron thinking/tool_choice"]` |
   | `ttl_source` del registro 13 | `confirmado por usage: escritura a 60 min` |
   | `ttl_source` del registro 15 | `confirmado por usage: escritura a 5 min` |
   | `notes` del registro 29 | `["pasaron 2078 s desde el final de #28 (TTL 1800 s, declarado en prompt_cache_options)"]` |
   | `diverge_at` del registro 32 | `msg0:system` |
   | `notes` del registro 40 | `["pasaron 398 s desde el final de #39 (TTL 300 s, supuesto: proveedor sin TTL conocido)"]` |
   | `model` del registro 41 | `None` |
   | `output` del registro 44 | `{no es json` |
   | ids con `server_side` verdadero | `[4, 33]` |

3. Genera el golden **una sola vez**: ejecuta TESTS con `-p 'test_replay.py'` y la variable `TAP_UPDATE_GOLDEN=1`.

## Verificación

- `test_known_values` pasa. Si falla, el escenario no es el previsto: no regeneres el golden, para y márcalo como `bloqueada`.
- TESTS completo, sin `TAP_UPDATE_GOLDEN`, acaba en `OK` dos veces seguidas.
- `tests/replay/golden.json` existe y contiene las cuatro claves `events`, `records`, `body_ids`, `log_lines`.
- El tamaño de `RAÍZ/data/requests.jsonl` no cambia por ejecutar los tests.
