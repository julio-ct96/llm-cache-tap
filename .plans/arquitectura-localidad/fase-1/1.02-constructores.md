# 1.02 Constructores de peticiones y respuestas

**Objetivo:** funciones que fabrican los cuerpos de petición y los trozos de respuesta que usará el escenario.

**Lee:** nada del proyecto. Este módulo no importa `tap` ni ningún otro fichero de `tests/`.

**Puedes tocar (nuevos):** `tests/replay/builders.py`, `tests/test_builders.py`.
Si `tests/__init__.py` o `tests/replay/__init__.py` no existen, créalos vacíos.

## Constantes

- `SYSTEMS`: `{"S1": "Eres un asistente de pruebas.", "S2": "Eres un asistente de pruebas. Responde breve."}`
- `RESPONSE_HEADERS`: `{"request-id": "req", "anthropic-ratelimit-requests-remaining": "99", "anthropic-ratelimit-tokens-remaining": "1000", "set-cookie": "a=b", "cf-ray": "x", "via": "1.1 proxy", "content-type": "text/event-stream"}`

## Cuerpos de petición (devuelven un diccionario)

**`turns(conv, n)`**: lista de mensajes `{"role", "content"}`. Para `i` de 1 a `n`: un mensaje `user` con contenido
`"<conv> pregunta <i>"` y, salvo en el último `i`, un mensaje `assistant` con contenido `"<conv> respuesta <i>"`. Devuelve `2n − 1` mensajes.

**`claude_body(model, conv, n, system="S1", tools=True, effort=None, thinking=False, system_ttl=None, mark_last=False, messages=None)`**. Claves, en este orden:

| Clave | Valor | Cuándo |
| --- | --- | --- |
| `model` | `model` | siempre |
| `max_tokens` | `1024` | siempre |
| `stream` | `True` | siempre |
| `tools` | `[{"name": "read_file", "description": "Lee un fichero", "input_schema": {"type": "object"}}, {"name": "run", "description": "Ejecuta un comando", "input_schema": {"type": "object"}}]` | si `tools` es verdadero |
| `system` | lista con un bloque `{"type": "text", "text": SYSTEMS[system], "cache_control": CC}`; `CC` es `{"type": "ephemeral"}` y, si `system_ttl` no es `None`, lleva además `"ttl": system_ttl` | siempre |
| `messages` | `messages` si se pasa; si no, `turns(conv, n)` | siempre |
| `output_config` | `{"effort": effort}` | si `effort` no es `None` |
| `thinking` | `{"type": "enabled", "budget_tokens": 2000}` | si `thinking` es verdadero |

Si `mark_last` es verdadero, el `content` del último mensaje pasa de ser un texto a ser la lista
`[{"type": "text", "text": <ese texto>, "cache_control": {"type": "ephemeral"}}]`.

**`responses_body(model, conv, n, effort=None, cache_options=False, raw_input=None)`**:
- Si `raw_input` no es `None`: devuelve solo `{"model": model, "stream": True, "input": raw_input}`.
- Si no, claves en este orden: `model`; `stream` = `True`; `instructions` = `"Eres un asistente."`;
  `tools` = `[{"type": "function", "name": "read_file"}]`; `input` = `turns(conv, n)`;
  `reasoning` = `{"effort": effort}` solo si `effort` no es `None`; `prompt_cache_options` = `{"ttl": "30m"}` solo si `cache_options` es verdadero.

**`chat_body(model, conv, n, system="S1", effort=None, retention=None, stream=True)`**. Claves en este orden: `model`; `stream`;
`tools` = `[{"type": "function", "function": {"name": "read_file"}}]`;
`messages` = `[{"role": "system", "content": SYSTEMS[system]}]` seguido de `turns(conv, n)`;
`reasoning_effort` = `effort` solo si no es `None`; `prompt_cache_retention` = `retention` solo si no es `None`.

## Trozos de respuesta (devuelven una lista de textos)

**`sse(*events)`**: une, por cada evento, el texto `data: ` + el evento + dos saltos de línea. Si el evento es un texto se usa tal cual;
si no, se serializa como JSON **compacto** (separadores `,` y `:` sin espacios) y sin escapar caracteres no ASCII.
El formato compacto es obligatorio: el código busca la secuencia exacta `"delta":{"content"`.

Cada constructor devuelve una lista de trozos; cada trozo es el resultado de una llamada a `sse` con los eventos de su fila.

**`anthropic_sse(read, write, inp, creation=None)`**: 3 trozos.

| Trozo | Eventos |
| --- | --- |
| 1 | `{"type": "message_start", "message": {"usage": U}}`, donde `U` = `{"input_tokens": inp, "cache_creation_input_tokens": write, "cache_read_input_tokens": read, "output_tokens": 1}`. Si `creation` es una pareja `(a, b)`, `U` lleva además `"cache_creation": {"ephemeral_5m_input_tokens": a, "ephemeral_1h_input_tokens": b}` |
| 2 | `{"type": "content_block_delta", "delta": {"type": "text_delta", "text": "Hola"}}` y `{"type": "content_block_delta", "delta": {"type": "text_delta", "text": " mundo"}}` |
| 3 | `{"type": "message_delta", "delta": {"stop_reason": "end_turn"}, "usage": {"output_tokens": 50}}` y `{"type": "message_stop"}` |

**`responses_sse(inp, cached)`**: 3 trozos.

| Trozo | Eventos |
| --- | --- |
| 1 | `{"type": "response.created", "response": {"id": "resp_1", "reasoning": {"effort": "medium"}}}` |
| 2 | `{"type": "response.output_text.delta", "delta": "Hola"}` y `{"type": "response.output_text.delta", "delta": " mundo"}` |
| 3 | `{"type": "response.completed", "response": {"usage": {"input_tokens": inp, "input_tokens_details": {"cached_tokens": cached}, "output_tokens": 80, "output_tokens_details": {"reasoning_tokens": 30}}}}` |

**`chat_sse(inp, cached)`**: 3 trozos.

| Trozo | Eventos |
| --- | --- |
| 1 | `{"object": "chat.completion.chunk", "choices": [{"delta": {"role": "assistant"}}]}` |
| 2 | `{"object": "chat.completion.chunk", "choices": [{"delta": {"content": "Hola"}}]}` y el mismo con `" mundo"` |
| 3 | `{"object": "chat.completion.chunk", "choices": [{"delta": {}, "finish_reason": "stop"}]}`, después `{"object": "chat.completion.chunk", "choices": [], "usage": {"prompt_tokens": inp, "prompt_tokens_details": {"cached_tokens": cached}, "completion_tokens": 40, "completion_tokens_details": {"reasoning_tokens": 5}}}` y por último el texto `[DONE]` |

**`anthropic_json(read, write, inp)`**: 1 trozo, JSON compacto (sin `data:`) de
`{"type": "message", "content": [{"type": "text", "text": "Hola"}], "stop_reason": "end_turn", "usage": {"input_tokens": inp, "cache_creation_input_tokens": write, "cache_read_input_tokens": read, "output_tokens": 50}}`.

**`chat_json(inp, cached)`**: 1 trozo, JSON compacto de
`{"object": "chat.completion", "choices": [{"message": {"content": "Hola"}, "finish_reason": "stop"}], "usage": {"prompt_tokens": inp, "prompt_tokens_details": {"cached_tokens": cached}, "completion_tokens": 40}}`.

## Tests (`tests/test_builders.py`)

1. `turns("A", 3)` tiene 5 mensajes; el primero es `user` con `"A pregunta 1"`; el segundo es `assistant` con `"A respuesta 1"`; el último es `user` con `"A pregunta 3"`.
2. `claude_body("m", "A", 1)` tiene exactamente las claves `model`, `max_tokens`, `stream`, `tools`, `system`, `messages`.
3. `claude_body("m", "A", 1, tools=False, effort="high", thinking=True, system_ttl="1h")`: no tiene `tools`; `output_config` es `{"effort": "high"}`; el `cache_control` del sistema es `{"type": "ephemeral", "ttl": "1h"}`; tiene `thinking`.
4. `claude_body("m", "A", 2, mark_last=True)`: el `content` del último mensaje es una lista de un bloque con `cache_control`.
5. `responses_body("m", "G", 1, raw_input="x")` es exactamente `{"model": "m", "stream": True, "input": "x"}`.
6. `chat_body("m", "H", 1)`: el primer mensaje tiene `role` `system`; hay 2 mensajes.
7. `anthropic_sse(1, 2, 3)` tiene 3 trozos; el segundo contiene `content_block_delta`; el primero empieza por `data: {`.
8. `anthropic_sse(1, 2, 3, (4, 5))`: el primer trozo contiene `"ephemeral_1h_input_tokens":5`.
9. El segundo trozo de `chat_sse(10, 0)` contiene la secuencia exacta `"delta":{"content"`.
10. El tercer trozo de `chat_sse(10, 0)` termina en `data: [DONE]` seguido de dos saltos de línea.
11. `json.loads` del único trozo de `chat_json(10, 4)` da `usage.prompt_tokens_details.cached_tokens` igual a 4.

## Verificación

TESTS con `-p 'test_builders.py'` acaba en `OK` con 11 tests.
