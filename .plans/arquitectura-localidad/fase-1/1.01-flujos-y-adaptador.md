# 1.01 Flujos falsos y adaptador

**Objetivo:** poder llamar a los hooks de `tap.py` desde un test, sin mitmproxy.

**Lee:** `tap.py`, solo las funciones `request`, `responseheaders`, `response`, `error` y el bloque de globales (líneas 22 a 50).

**Puedes tocar (todos nuevos):** `tests/__init__.py`, `tests/replay/__init__.py`, `tests/replay/flows.py`,
`tests/replay/adapter.py`, `tests/test_flows.py`. No modifiques `tap.py`.

## Pasos

1. Crea `tests/__init__.py` y `tests/replay/__init__.py` vacíos.

2. Crea `tests/replay/flows.py` con tres clases. No importan nada de `tap`.

   | Clase | Constructor | Atributos |
   | --- | --- | --- |
   | `FakeRequest` | `(method, host, path, text, start)` | `method`; `pretty_host` = host; `path`; `headers` = diccionario vacío; `raw_content` = `text` en bytes UTF-8; `timestamp_start` = start; `timestamp_end` = start + 0.05 |
   | `FakeResponse` | `(status, headers, start)` | `status_code` = status; `headers` = copia del diccionario recibido; `timestamp_start` = start; `stream` = `None` |
   | `FakeFlow` | `(request)` | `request`; `response` = `None`; `metadata` = diccionario vacío; `error` = `None` |

   `FakeRequest` tiene además el método `get_text(strict=True)`, que devuelve `text`.

3. Crea `tests/replay/adapter.py`. Es el **único** fichero de `tests/` que importa `tap`. Funciones:

   | Función | Qué hace |
   | --- | --- |
   | `hooks()` | devuelve el módulo `tap` (tiene `request`, `responseheaders`, `response`, `error`) |
   | `reset(log_path)` | vacía `tap.RECORDS`, `tap.BODIES` y `tap.CLIENTS` con `.clear()`; pone `tap.STATE["next_id"]` y `tap.STATE["next_conv"]` a 1; asigna `tap.LOG = log_path` (un `pathlib.Path`) |
   | `records()` | lista con una copia de cada registro de `tap.RECORDS`, en su orden, sin las claves que empiezan por `_` |
   | `body_ids()` | lista ordenada de las claves de `tap.BODIES` |
   | `subscribe()` | crea un `queue.Queue`, lo añade a `tap.CLIENTS` y lo devuelve |
   | `set_max(n)` | asigna `tap.MAX = n` y devuelve el valor anterior |
   | `handler()` | devuelve la clase `tap.Handler` |

4. Crea `tests/test_flows.py` con un `unittest.TestCase` y un test:
   - `setUp`: crea un directorio temporal (`tempfile.TemporaryDirectory`, con `addCleanup`) y llama a `adapter.reset` con la ruta `requests.jsonl` dentro de él.
   - Construye un `FakeFlow` con un `FakeRequest` de método `POST`, host `api.anthropic.com`, ruta `/v1/messages`, start `1790000000.0` y, como texto,
     el JSON de `{"model": "claude-opus-5-5", "messages": [{"role": "user", "content": "hola"}]}`.
   - Llama a `adapter.hooks().request(flow)`.
   - Comprueba: `adapter.records()` tiene 1 elemento; su `id` es 1; su `state` es `"pending"`; su `model` es `"claude-opus-5-5"`;
     `flow.request.headers["accept-encoding"]` vale `"identity"`; `flow.metadata["tap_id"]` vale 1; `adapter.body_ids()` es `[1]`.

## Verificación

- TESTS con `-p 'test_flows.py'` acaba en `OK` con 1 test.
- `grep -rn "import tap" RAÍZ/tests` muestra una sola línea, en `tests/replay/adapter.py`.
- El tamaño de `RAÍZ/data/requests.jsonl` no cambia por ejecutar el test.
