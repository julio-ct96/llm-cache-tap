# 3.04 JS: `list.js`

**Objetivo:** sacar de `app.js` la tabla de peticiones, sus filtros y los contadores de la cabecera.

**Lee:** `ui/app.js`: desde el principio hasta el comentario `// ---------- detail ----------`. `fase-3/lista-ui.md`.

**Puedes tocar:** `ui/list.js` (nuevo), `ui/app.js`.

## Pasos

1. Crea `ui/list.js` y mueve a él, sin cambios:

   | Elemento | Con `export` |
   | --- | --- |
   | `BAD_VERDICTS` | no |
   | `SELECT_FILTERS` | sí |
   | `TOGGLE_FILTERS` | sí |
   | `pressed` | sí |
   | `passes` | no |
   | `rowHtml` | no |
   | `render` | sí |
   | `syncFilters` | sí |
   | `resetFilters` | sí |

2. Imports de `ui/list.js`:
   - de `state.js`: `state`;
   - de `format.js`: `$`, `esc`, `num`, `secs`;
   - de `parts.js`: `badge`, `shareBar`;
   - de `cache-timer.js`: `ttlOf`, `timerHtml`, `tick`.

3. En `ui/app.js`: añade un import de `list.js` con `SELECT_FILTERS`, `TOGGLE_FILTERS`, `pressed`, `render`, `syncFilters` y `resetFilters`.
   De los demás imports quita los nombres que `app.js` ya no use (mismo criterio que en la tarea 3.03).
