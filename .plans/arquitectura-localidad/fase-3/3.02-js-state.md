# 3.02 JS: `state.js`

**Objetivo:** reunir en un objeto el estado mutable que comparten la lista, el detalle y el stream, para poder repartirlos después en módulos.

**Contexto:** un módulo no puede reasignar una variable `let` de otro módulo. Por eso las cinco variables pasan a ser propiedades de un objeto compartido.

**Lee:** `ui/app.js` entero. `fase-3/lista-ui.md`.

**Puedes tocar:** `ui/state.js` (nuevo), `ui/app.js`.

## Pasos

1. Crea `ui/state.js` con un único `export const state`: un objeto con estas propiedades y valores iniciales, conservando los comentarios que hoy acompañan a cada variable:

   | Propiedad | Valor inicial |
   | --- | --- |
   | `recs` | un `Map` vacío |
   | `visible` | lista vacía |
   | `successors` | un `Map` vacío |
   | `selected` | `null` |
   | `ttl` | `300` |

2. En `ui/app.js`: importa `state` de `state.js` y elimina las cinco declaraciones (`const recs`, `let visible`, `let successors`, `let selected`, `let ttl`).

3. **Antes de sustituir nada**, en la función `timerHtml` renombra la constante local `state` a `expiry`. Son tres apariciones, en las tres últimas líneas de la función:
   `const state = age < ...`, `state === 'dudosa'` y `${state}`. Si no se renombra, esa constante tapa al objeto `state` importado y la función falla al ejecutarse.
   No toques `r.state` (propiedad del registro) ni `{ state: treeStates.get(key), depth }` (nombre de una opción).

4. Sustituye **cada uso** de esas variables por `state.<nombre>`. Lista completa de usos:

   | Variable | Función o bloque | Usos |
   | --- | --- | --- |
   | `recs` | `rowHtml` | 1 (`recs.get`) |
   | `recs` | `render` | 4 (dos `recs.values()`, dos `recs.size`) |
   | `recs` | `syncFilters` | 1 |
   | `recs` | `source.onmessage` | 4 (dos `recs.clear()`, dos `recs.set`) |
   | `visible` | `render` | 5 |
   | `visible` | manejador de `keydown` | 4 |
   | `successors` | `timerHtml` | 1 |
   | `successors` | `render` | 3 |
   | `successors` | `summaryHtml` | 1 |
   | `selected` | `rowHtml` | 1 |
   | `selected` | `loadBody` | 1 |
   | `selected` | `showDetail` | 2 |
   | `selected` | `closeDetail` | 1 |
   | `selected` | manejador de `toggle` | 1 |
   | `selected` | manejador de `keydown` | 2 |
   | `selected` | `source.onmessage` | 3 |
   | `ttl` | `ttlOf` | 1 |
   | `ttl` | `source.onmessage` | 1 (`ttl = ev.ttl`) |

   **No** se sustituyen, porque no son estas variables:
   - `ev.recs` en `source.onmessage` (propiedad del evento);
   - el texto `'selected'` en `rowHtml` y el selector `tr.selected` en `showDetail` (clase CSS);
   - `ttl: total` en `tick` (desestructuración de `dataset`), y los textos `ttl`, `ttl-bar`, `ttl-text`, `data-ttl`;
   - los nombres `ttlOf`, `ttlLabel`, `ttl_s`, `ttl_max_s`, `ttl_source`, `ttl_anchor`.
