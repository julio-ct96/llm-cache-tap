# 3.00 Test de recursos de la interfaz

**Objetivo:** un test que detecte rutas rotas e imports mal escritos en `ui/` sin abrir un navegador.

**Lee:** `ui/index.html` (solo las etiquetas `<link>` y `<script>`), la primera línea de `ui/app.js` y las líneas con `url(` de `ui/tokens.css`.

**Puedes tocar (nuevo):** `tests/test_ui_assets.py`. Si `tests/__init__.py` no existe, créalo vacío.

## Pasos

Crea `tests/test_ui_assets.py`. La carpeta `ui/` se localiza a partir de la ruta del propio test (`tests/` y `ui/` son hermanas). No importes `tap` ni `cachetap`.
Tres tests:

1. **Recursos de `index.html`.** Reúne los valores de todos los atributos `href="..."` y `src="..."` de `ui/index.html`.
   Descarta los que empiezan por `data:`, `http` o `#`. Cada uno de los restantes debe ser un fichero existente, resuelto respecto a `ui/`.

2. **Recursos de las hojas de estilo.** Para cada fichero `.css` bajo `ui/` (en cualquier subcarpeta), reúne las rutas de cada `url('...')` o `url("...")`.
   Descarta las que empiezan por `data:` o `http`. Cada una debe ser un fichero existente, resuelto respecto a la carpeta de ese `.css`.

3. **Imports de JavaScript.** Para cada fichero `.js` de `ui/`, reúne cada sentencia `import { ... } from './otro.js'` (puede ocupar varias líneas). Para cada una:
   - el fichero importado debe existir, resuelto respecto a `ui/`;
   - cada nombre de la lista debe estar exportado por ese fichero. Un nombre está exportado si el fichero contiene
     `export function <nombre>`, `export async function <nombre>`, `export const <nombre>`, `export let <nombre>` o `export class <nombre>`.
     Si el import usa `a as b`, el nombre que se comprueba es `a`.

Cuando falle, el mensaje debe decir el fichero de origen y la ruta o el nombre que falta.

## Verificación

- TESTS con `-p 'test_ui_assets.py'` acaba en `OK` con 3 tests sobre el código actual.
- Prueba que detecta un fallo: cambia temporalmente en `ui/app.js` el nombre `jsonTree` del import por `jsonTreeX`, ejecuta el test (debe fallar nombrando `jsonTreeX`) y **deshaz el cambio**. Confirma con TESTS que vuelve a `OK`.
