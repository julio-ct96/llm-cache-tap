# 1.04 Copilot por proveedor

**Objetivo:** `cachetap/prices/copilot.py` construye `PRICES` uniendo bloques con nombre: lo heredado de las listas, lo que GitHub cobra distinto y lo que solo lista GitHub, agrupado por proveedor. Los precios no cambian.

**Contexto:** el orden de la unión importa. Los bloques que corrigen una fila heredada (`gpt-5.6-luna`, `gpt-4.1`, `gpt-4o`, `gpt-4o-mini`) tienen que ir **después** de `FROM_LISTS` para ganar. Los nombres `anthropic`, `base`, `google` y `openai` ya son módulos importados: no los uses para constantes.

**Lee:** `cachetap/prices/copilot.py`, desde el comentario «US dollars per million tokens» hasta el final de `PRICES`.

**Puedes tocar:** `cachetap/prices/copilot.py`.

## Pasos

1. Sustituye el diccionario literal de `PRICES` por estas constantes, en este orden, anotadas como `dict[str, base.Price]`. Mueve con cada entrada su comentario actual, si lo tiene:

   | Constante | Entradas (valores tal como están hoy) |
   | --- | --- |
   | `FROM_LISTS` | las dos líneas de comprensión que heredan de `anthropic.PRICES` y `openai.PRICES` |
   | `DIFFERENT_TIERS` | `"gpt-5.6-luna"` |
   | `UTILITY_MODELS` | `"gpt-4.1"`, `"gpt-4o"`, `"gpt-4o-mini"` |
   | `GEMINI` | `"gemini-3.5-flash"`, `"gemini-3.6-flash"`, `"gemini-3.7-flash"`, `"gemini-3.8-flash"`, `"gemini-4-argon"`, `"gemini-4-carbon"`, `"gemini-4-hydrogen"` |
   | `GROK` | `"grok-4.5"`, `"grok-4.6"`, `"grok-4.7"` |
   | `KIMI` | `"kimi-k3"`, `"kimi-k2.7-code"` |
   | `MAI` | `"mai-code-1.1-flash"` |

2. Deja encima de `FROM_LISTS` el comentario de la fuente («US dollars per million tokens; see …» y las dos líneas siguientes).

3. `PRICES: dict[str, base.Price] = {**FROM_LISTS, **DIFFERENT_TIERS, **UTILITY_MODELS, **GEMINI, **GROK, **KIMI, **MAI}`.

4. No toques `_single_write`, `_one_write_rate`, `_without_12h`, `_UTILITY`, `_grok` ni `AFTER_PROMO`.

5. Ejecuta FORMATO sobre el fichero.
