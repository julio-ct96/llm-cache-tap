# 2.04 Copilot: Opus 4.8 en modo rápido

**Objetivo:** la tarifa de Copilot incluye `claude-opus-4.8-fast`, la variante de modo rápido que GitHub cobra aparte.

**Contexto:** fila de https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing: «Claude Opus 4.8 (fast mode) (preview) … $10.00 | $1.00 | $12.50 | $50.00», es decir, entrada, lectura, escritura y salida. El ID `claude-opus-4.8-fast` es el que lista el catálogo de Copilot que usa OpenCode. MAI Code 2 y MAI Code 2 Flash **no** se añaden: GitHub no publica su ID.

**Lee:** en `cachetap/prices/copilot.py`, las constantes de bloque (`FROM_LISTS` … `MAI`) y `PRICES`. En `tests/test_prices.py`, `ReferenceTest.test_rows`.

**Puedes tocar:** `cachetap/prices/copilot.py`, `tests/test_prices_copilot.py`, `tests/test_prices.py`.

## Pasos

1. En `cachetap/prices/copilot.py`, añade después de `UTILITY_MODELS` la constante `CLAUDE_FAST: dict[str, base.Price] = {"claude-opus-4.8-fast": {"input": 10, "read": 1, "write": 12.5, "output": 50}}`, con un comentario en inglés encima: `fast mode is a separate model that only GitHub prices`.

2. `PRICES` pasa a `{**FROM_LISTS, **DIFFERENT_TIERS, **UTILITY_MODELS, **CLAUDE_FAST, **GEMINI, **GROK, **KIMI, **MAI}`.

4. En `tests/test_prices.py`, `test_rows`: `len(rows), 127` pasa a `len(rows), 128`.
